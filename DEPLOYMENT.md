# Обновление и запуск после 16 сентября 2026

Рабочий VPS сейчас выключен до оплаты владельцем. Изменения в Git сами по себе не обновляют сервер.

## Порядок обновления

1. Сделать резервную копию PostgreSQL и шифрованного файлового хранилища; ключ шифрования хранить отдельно. Проверить восстановление в изолированной среде.
2. Установить зависимости: `python -m pip install -r requirements.txt`.
3. Проверить настройки `.env`: случайные SESSION_SECRET и DOCUMENT_ENCRYPTION_KEY, правильные DATABASE_URL и PUBLIC_BASE_URL, HTTPS и защищённые cookie. Не менять существующий ключ шифрования без отдельной процедуры перешифрования — старые файлы иначе не откроются.
4. Остановить приложение на время совместимого обновления, применить `python -m alembic upgrade head`, запустить обновлённый код.
5. Проверить healthz, вход сотрудника, получение каталога, тестовую заявку с вымышленными данными и отправку минимального уведомления. Не отправлять настоящие персональные данные для проверки.

Миграция `d6a9e1609202` добавляет снимки согласий к клиентам и заявкам. Старые записи получают пустой объект: нового согласия задним числом не возникает. Новые заявки сохраняют версию, текст, реквизиты оператора, время и канал. Виджет передаёт `consent_version` и `consent_fingerprint` — SHA-256 показанного текста; при смене текста или реквизитов устаревшую страницу необходимо обновить. Telegram и MAX также привязывают подтверждение к показанному тексту. Архив текста 2026-08-26 сохранён отдельно от текущего текста 2026-09-16.

Telegram-уведомление сотруднику содержит номер заявки и ссылку `/staff` с обязательным входом. Имя, телефон, услуга и комментарий в уведомление не включаются. Если клиент сам общается с ботом Telegram, введённые им сведения всё равно проходят через Telegram — минимизация уведомлений не устраняет этот отдельный поток.

## Проверки

`python -m pytest -q` использует только TEST_DATABASE_URL. Тестовая база пересоздаётся: никогда не задавайте адрес рабочей базы. `ruff check --select E9,F63,F7,F82 app tests` проверяет критические ошибки Python. GitHub Actions запускает тесты на собственной PostgreSQL и проверяет синтаксис JavaScript витрины.
