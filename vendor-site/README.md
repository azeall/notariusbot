# Сайт сервиса

Витрина продукта: что это, как работает, что входит, как подключиться.
Отдельный сайт, никак не связанный с сайтами нотариусов.

Обычная статика — ни сборки, ни зависимостей. Открывается двойным щелчком
по `index.html`, деплоится куда угодно.

## Деплой на Vercel

Отдельный проект, у которого **Root Directory = `vendor-site`**. Тогда он
собирается сам по себе и не мешает сервису заявок в том же репозитории.

Ссылки «Войти» и «Кабинет владельца сервиса» ведут на `/platform/login`.
Если сайт стоит на другом домене, чем сервис заявок, замените их на полный
адрес сервиса в `index.html`.

## Дизайн

Современный минимализм: почти чёрно-белое, один акцент `#2f5bea`, крупные
заголовки, много воздуха, декора нет. Всё держится на типографике и отступах,
поэтому менять проще всего через переменные в начале `style.css`.
