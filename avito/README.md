# Картинки и текст для объявления

## Что здесь

`*.svg` — исходники нарисованных слайдов. Правятся в `make_slides.py`,
пересобираются командой `python make_slides.py`.

`*.png` — готовые картинки 1200×900 и 1440×1080 (обе пропорции 4:3,
Авито показывает их без обрезки).

`render.html` — страница, показывающая все слайды разом. Нужна для проверки.

## Как сняты снимки сайта (07–11)

Сайт нотариуса собран локально с временным демонстрационным наполнением
(«Иванова Мария Сергеевна», московский телефон), баннер cookie снят на время
съёмки. В репозиторий эти правки не попали: после съёмки всё возвращено через
`git checkout`. На боевом сайте по-прежнему заглушки — их заполняет нотариус.

Снимки сделаны безголовым Chrome:

    chrome --headless --screenshot=out.png --window-size=1440,1080 <адрес>

## Чего на картинках нет намеренно

Телефона, почты, ссылок и QR — за них Авито снимает объявление
с публикации.
